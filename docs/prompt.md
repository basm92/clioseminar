## Prompt

Create a website for a newly-founded seminar series in Utrecht, the Netherlands, titled the "Cliometrics Seminar". The website should be a git repository and hosted on github actions, and continuously integrated after commits and pushes to main. The website should use hugo as an engine. This should be the hugo theme: https://hugodoit.pages.dev/. The image @clio_seminar_crop.png should be on the main page but there should be no other avatar. 

## Main page

Main page should have a **short** description about the seminar, with the "slogan" of "Historically informed economics, or economically informed historical research; preferably both." The main page should show a schedule in the form of a table. It should be stressed that the seminar will be in Utrecht city center, at a walking distance from the railway station. 

This should also be on the main page:

Depending on interest, we can decide to devote specific slots to real-early stage research or research proposals (with several shorter presentations per seminar slot). This should not be done before the series is up and running, and before we have been able to measure interest. Similarly, we can devote specific slots to reading group-style discussions of important books or papers in the field. However, it might be better to leave this up to individual initiative of seminar participants.
